# hear_model

## Setup

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Vendored code

at commit `36bbb90879545a2f1106668048b1a12a61ff2a0d` (2025-07-03). Do not edit it in place;
to update, replace the directory with a newer upstream checkout and bump the commit above.
